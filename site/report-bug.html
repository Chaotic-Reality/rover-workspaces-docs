Support homeReport a bugIssue updates
Reports are public. This form publishes to ROVER’s public GitHub issue tracker, even though the beta website requires tester sign-in. Do not include workspace exports, private URLs, emails, passwords, tokens, or browsing history. There are no attachments or automatic diagnostics. For a sensitive or security problem, submit only a request for a private conversation.

Live reports require the protected beta support service. This static preview does not submit reports.

ROVER means Restore, Organize, View, Explore, Repeat.

Make room for focus. This is a development beta; store availability and cloud services have not been announced.
