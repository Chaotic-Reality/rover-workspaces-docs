Set up your ROVER beta.

Use the reviewed ZIP supplied by the maintainer. There is no public store download yet. Keep your testing browser profile separate from your everyday work.

Back up first

In Appearance & settings, download a Full local backup to keep workspaces, collections, favorites, appearance, Custom Templates, and saved revisions together. Older JSON/YAML workspace exports cover only workspace content. Keep the original backup until you have verified the upgrade.

Unzip into a stable folder

Keep the supplied build record and checksum with the ZIP. Extract the extension files into a folder you will continue using for updates. The folder containing manifest.json is the one you load. Do not load the ZIP itself.

Load in Chrome or Edge

Open chrome://extensions in Chrome or edge://extensions in Edge. Enable Developer mode, choose Load unpacked, and select that folder. Open ROVER from the extension menu. Each browser profile has its own local data.

Test before replacing your working copy

Capture a few harmless tabs and groups. Check save, reload, ordering, selective restore, collections, theme, and export/import. Check both a narrow and a short window. Use disposable tabs when testing Reload current window, which closes existing tabs except ROVER.

Update in place

Back up again. Replace files in the same extension folder and use Reload on the extensions page. Avoid uninstalling or changing the loaded folder: unpacked extension identity can change and existing local data may appear absent. Keep the old folder and backup for recovery.

What can I test?

Local workspaces, restoration, editing, collections, Custom Templates, and local history are implemented. A manually started 15-day trial unlocks local Pro controls. Google/Microsoft sign-in, Google Drive/OneDrive backups, and live cross-browser sync are still being prepared. The website does not collect payment.

Report the build ID, browser version, viewport, steps, expected behavior, and actual behavior. Do not attach private exports, account tokens, or sensitive URLs to public issues.
