Private by design

Your workspace stays yours.

The current beta stores workspace data in extension-local storage in your browser profile. Extension account connection, telemetry, and workspace cloud upload are not enabled. The protected website offers a separate optional Google sign-in test.

What is stored

Workspace names, descriptions, URLs, tab titles, groups, collections, preferences, and local history. Opt-in daily capture runs locally at your chosen time and is off by default.

What is not copied

ROVER does not copy cookies, passwords, sign-ins, form contents, private browsing sessions, or browser history.

Your controls

Download a Full local backup from settings, export workspaces, delete local records, or uninstall the extension after backing up. Review exported URLs and titles before sharing them.

Checking for updates

Choosing Check for updates opens the protected beta website with only your installed version in the URL. It does not send workspace names, tabs, or saved content. The extension does not poll the website in the background.

Beta website access

Approved testers enter an email verification code through Cloudflare Access. Cloudflare processes website connection and security information and uses session cookies and bot checks. This does not upload saved workspaces or enable ROVER account sync.

Account connection preparation

The website's optional Google sign-in displays your verified name and picture in the top-right Account menu when available. Those display details last only in the short-lived website session, outside workspace backups. Google receives the browser request for a Google-hosted picture without a page referrer. Website sign-in does not enable sync or Drive access.

The extension's Account dialog remains disabled for sign-in. Its prepared flow uses the browser's sign-in window and optional access only to this beta website. No workspace content is sent. Connection tokens will stay in browser-session storage outside backups. Browser sign-out and website sign-out are separate. Offline sign-out clears locally and reports that server revocation was not confirmed.

Voluntary bug reports publish the details you enter to the public GitHub issue tracker after confirmation. The form does not automatically upload your saved workspaces or tester email. Never include private information.
